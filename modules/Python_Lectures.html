Variables & Memory

A variable is a name given to a memory location in a program.

Rules for Identifiers

  1. Can combine uppercase, lowercase, digits, and underscore (_)
  2. Cannot start with a digit (e.g., 1variable is invalid)
  3. No special symbols like !@#$%
  4. Can be of any length
Valid: myVariable, variable_1, variable_for_print
Invalid: 1variable, my@var

Type Conversion vs Type Casting

Implicit (Conversion)

a, b = 1, 2.0
sum_val = a + b  # 3.0 (auto-converted)

Explicit (Casting)

a, b = 1, "2"
c = int(b)
sum_val = a + c  # 3
Error: a, b = 1, "2" ; sum = a + b will raise a TypeError because you cannot add int and str directly.

Lecture 3: Lists & Tuples

Lists in Python

A built-in data type that stores a set of values. It can store elements of different types.

marks = [87, 64, 33, 95, 76]
student = ["Karan", 85, "Delhi"]
student[0] = "Arjun"  # Allowed (Mutable)
print(len(student))    # 3

List Slicing

Same as string slicing.

marks = [87, 64, 33, 95, 76]
print(marks[1:4])   # [64, 33, 95]
print(marks[:4])    # [87, 64, 33, 95]
print(marks[1:])    # [64, 33, 95, 76]
print(marks[-3:-1]) # [33, 95]

List Methods

MethodDescriptionExample

list.reverse()Reverses list[2,1,3] → [3,1,2]
list.insert(idx, el)Inserts at index[2,1,3] → [2,1,4,3]
list.remove(1)Removes first occurrence[2,1,3,1] → [2,3,1]
list.pop(idx)Removes element at index[2,1,3] → [2,3]

Lecture 4: Dictionary & Set

Dictionary in Python

Used to store data values in key:value pairs. They are unordered, mutable, and don't allow duplicate keys.

dict = {
    "name" : "shradha",
    "cgpa" : 8.5,
    "marks": [98, 97, 95]
}

print(dict["name"])    # Access
dict["key"] = "value"  # Assign or Add new

Nested Dictionaries

student = {
    "name" : "shradha",
    "score": {
        "chem": 98,
        "phy" : 97,
        "math": 95
    }
}

print(student["score"]["math"])  # 95

Dictionary Methods

MethodDescription
myDict.keys()Returns all keys

myDict.items()Returns all (key, val) pairs as tuples
myDict.get("key")Returns value for key (safe access)
myDict.update(newDict)Inserts specified items

Lecture 5: Loops

While Loops

Used to repeat instructions while a condition is true.

# Print hello 5 times
count = 1
while count <= 5:
    print("hello")
    count += 1

# Print numbers 1 to 5
i = 1
while i <= 5:
    print(i)
    i += 1

Break & Continue

Break

Terminates the loop immediately when encountered.

# Stop search when found
for i in range(10):
    if i == 5:
        break
    print(i)

Continue

Skips current iteration and moves to next.

# Skip multiples of 3
for i in range(10):
    if i % 3 == 0:
        continue
    print(i)

For Loops

Used for sequential traversal: list, string, tuple.

for el in list:
    # some work

# For loop with else
for el in list:
    print(el)
else:
    print("END")  # Runs when loop ends normally (not via break)

Range Function

range(start?, stop, step?) — returns a sequence of numbers.

range(5)        # 0, 1, 2, 3, 4
range(1, 6)     # 1, 2, 3, 4, 5
range(1, 10, 2) # 1, 3, 5, 7, 9

Pass Statement

A null statement that does nothing. Used as a placeholder.

for el in range(10):
    pass  # placeholder for future code

Lecture 6: Functions

Defining Functions

A block of statements that perform a specific task.

def sum(a, b):
    s = a + b
    return s

print(sum(2, 3))  # 5

Built-in vs User-defined Functions

Built-in

  • print()
  • len()
  • type()
  • range()

User-defined

Functions created by the programmer using def.

Default Parameters

Assigning a default value to a parameter, used when no argument is passed.

def greet(name="Guest"):
    print("Hello,", name)

greet()          # Hello, Guest
greet("Alice")   # Hello, Alice

Recursion

When a function calls itself repeatedly. Must have a base case to stop.

# Print n to 1 backwards
def show(n):
    if n == 0:
        return
    print(n)
    show(n-1)

# Factorial
def fact(n):
    if n == 0 or n == 1:
        return 1
    return n * fact(n-1)

Lecture 7: File I/O

File Types

Text Files

.txt, .docx, .log etc.

Binary Files

.mp4, .mov, .png, .jpeg etc.

Open, Read & Close

f = open("sample.txt", "r")  # r : read mode
data = f.read()
f.close()
ModeMeaning
rRead mode
wWrite mode (overwrites)
aAppend mode (adds to file)

Reading Methods

data = f.read()      # Reads entire file
data = f.readline()  # Reads one line at a time

Writing to a File

f = open("demo.txt", "w")
f.write("this is a new line")  # Overwrites entire file
f.close()

f = open("demo.txt", "a")
f.write("this is a new line")  # Adds to the file
f.close()

With Syntax (Recommended)

Automatically closes the file after the block.

with open("demo.txt", "a") as f:
    data = f.read()

Deleting a File

Using the os module.

import os
os.remove("filename")
Module: A file written by another programmer that has functions we can use.

Lecture 8: OOP in Python

What is OOP?

To map with real world scenarios, we use objects in code. This is called Object Oriented Programming.

class Student:
    name = "karan kumar"  # Class attribute

s1 = Student()
print(s1.name)

__init__ Function (Constructor)

Always executed when an object is created. self refers to the current instance.

class Student:
    def __init__(self, fullname):
        self.name = fullname

s1 = Student("karan")
print(s1.name)  # karan

Methods

Functions that belong to an object.

class Student:
    def __init__(self, fullname):
        self.name = fullname

    def hello(self):
        print("hello", self.name)

s1 = Student("karan")
s1.hello()  # hello karan

Static Methods

Methods that don't use the self parameter (work at class level). Use the @staticmethod decorator.

class Student:
    @staticmethod
    def college():
        print("ABC College")

# Decorators wrap another function to extend
# behaviour without permanently modifying it.

Important Concepts

Abstraction

Hiding the implementation details of a class and only showing the essential features to the user.

Encapsulation

Wrapping data and functions into a single unit (object).
